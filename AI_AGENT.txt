ИНСТРУКЦИЯ ДЛЯ AI-АГЕНТА (Go-парсер ЕИС)
=======================================
Проект: парсинг zakupki.gov.ru → структуры → СУБД.
Язык: Go. Образцы: ../html/44 фз/, ../html/223 фз/
Гайды: ../result/ (00–13). Этот файл — краткий контекст, не дублирует всё.


ЖЁСТКИЕ ПРАВИЛА
---------------
1. Весь код (Go, скрипты запуска парсера, tenders.csv) — ТОЛЬКО в DataCode/.
2. Не изменять ../html/ и ../over/.
3. Не переиспользовать селекторы 44 на страницах 223 notice (и наоборот).
4. Два парсера: ParseNotice44 / ParseNotice223 (общий только HTTP, money, dates).
5. Поля извлекать по подписи (label→value), не по порядковому номеру span.
6. Filestore:
   44 → /44fz/filestore/.../priz/file.html?uid=
   223 → /223/filestore/.../fz223/file.html?uid=
7. Rate limit: ≤3 concurrent, retry на 429 и пустой body.
8. Тесты: на файлах из html/44 фз и html/223 фз (go embed или testdata).
