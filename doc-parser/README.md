# doc-parser

Сервис перевода документов в текстовый формат.

## Назначение

`doc-parser` принимает документы (PDF, Office, изображения и др.) и возвращает извлечённый текст.

## Развёртывание

Каталог `doc-parser/` — место для кода и конфигурации нового сервиса внутри этого репозитория. Реализация API и сборки добавляется сюда отдельно.

## Связь с проектом

Рядом в репозитории уже есть extract в `zakupki-parser` (`POST /api/v1/extract`). Этот сервис задуман как отдельный выделенный сервис той же задачи: документ → текст.
